## 六、一次点击的完整调用链

以点顶栏「启动」为例，把整条路走一遍 —— 理解这条链，
改任何功能都能自己推断出该动哪一层：

```
用户点「启动」
  │
  ├─ index.html   顶栏按钮（onclick 或 bindEvents 里的监听）
  │
  ├─ main.js  toggleRun()                          L1562
  │     └─ call('StartFrp')                        L97  → window.go.main.App.StartFrp()
  │
  ├─ app.go   (a *App) StartFrp()
  │     ├─ cfgfile.Save()      确保 frpc.toml 是最新的      internal/cfgfile
  │     └─ frpcman.Manager.Start()                          internal/frpcman
  │           └─ exec.Command("frpc.exe", "-c", "frpc.toml")
  │                 └─ 抓 stdout 管道
  │
  ├─ frpcman 读管道 → logparse.ParseLine()
  │     ├─ 剥掉 ANSI 颜色转义
  │     ├─ 匹配 rules 表 → 翻译成中文
  │     └─ 看到 "login to server success" → 状态 = connected
  │
  ├─ frpcman 状态变化
  │     ├─ 存进日志缓冲（供 GetLogs 增量拉取）
  │     └─ 发事件 frp:state
  │
  ├─ main.js  收到 frp:state → refreshState()
  │     └─ call('GetState') → renderTopbar()
  │
  └─ 顶栏变成 🟢 已连接到服务端
```
